Design Section 1 — Node Architecture

What lives in the constellation, how it's typed, sized, and colored

Entity Types & Visual Treatment

Contractor

Shape: Large sphere (r=18-28)
Size: Scales with total NCE exposure
Color: Severity — red >20%, orange >10%, green <8%
Inner ring: Partial arc = % of variation vs portfolio avg
Label: Name + £ value

Early Warning

Shape: Small filled sphere (r=8-14)
Size: Scales with projected CE cost
Color: Purple (open) / amber (stale >14d) / red (critical)
Animation: Pulsing ring if stale
Label: "EW" + ID number

NCE / Claim

Shape: Rounded square (distinguishes from circular EWs)
Size: Scales with claim value
Color: Amber (normal) / red (flagged — validity issue or salami pattern)
Label: "NCE" + £ value

Package

Shape: Hexagon (distinct from spheres and squares)
Size: Scales with contract value
Color: Teal (on-track) / amber (drifting) / red (bleeding)
Label: Package code

Connection Types

Contractual — contractor ↔ package (solid, teal, animated particle)
Risk link — EW/NCE ↔ source entity (colored by severity)
Cascade — risk-to-risk dependency (dashed, purple, the "aha" lines)
Pattern — AI-detected relationship (salami slicing, budget bleed cluster)

Hub (Centre)

The hub is the programme itself. Always visible. Shows the headline number (total exposure). All contractor nodes connect to it. Acts as the gravitational anchor.

In 3D: The hub is a glowing sphere at the origin. Contractors orbit at ~radius 8-12. Events/EWs/NCEs orbit their parent contractor at radius 3-5. Creates a natural solar-system hierarchy.
