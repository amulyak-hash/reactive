What kind of motion?

"Smooth as butter, simple yet effective." Here are three animation vocabularies — each one is restrained, but they feel different.

A

Precision Kinetic

Numbers count up with spring easing. Text slides in with translateY(12px) → 0 and opacity fades. Elements stagger with 80ms delays. Everything feels engineered and exact.

Signature moves
• Number counters (spring)
• Text fade-up (ease-out)
• Staggered reveals
• Scale 0.95 → 1.0 on enter
Feels like
Apple product page.
Stripe dashboard.
Linear app transitions.
B

Cinematic Breath

Slower, more deliberate. Elements breathe — subtle scale pulses on key numbers, slow fades between beats (400-600ms), spotlight effects that draw focus. Transitions feel like scene changes in a film. Silence between moments.

Signature moves
• Slow crossfades between scenes
• Gentle scale breathing on focus
• Light bloom / glow pulses
• Parallax depth on scroll
Feels like
Nolan film title sequence.
Bloomberg visual story.
Museum exhibit.
C

Precision + Cinematic Hybrid

Precision kinetics for the data moments (numbers count, elements stagger in), cinematic breath for the emotional beats (scene transitions, the Afcons reveal, the acceleration pulse). The motion style matches the story moment.

When to use which
Precision: numbers appearing, contractor names entering, data reveals

Cinematic: scene transitions, the "13p" moment, Afcons glow, the acceleration heartbeat
Feels like
The motion serves the narrative.
Tight when showing data.
Atmospheric when building tension.
Tech note
All three are achievable with CSS animations + a lightweight library (Framer Motion or GSAP). No canvas needed for the story card itself — pure DOM + CSS transforms for 60fps butter.
